# ui/components

Owner: UI lane. Griffin-system React components for the product routes under `/app`:
`shell/` (header, system chip, banners, footer), `ui/` (pill button, chip, tabs, sheet, dialog, popover, menu, toast, fields),
`inbox/` (queue), `new/` (upload and typed forms), `review/` (decision card, fact sheet, letter, sweep, Nemotron panel, layout),
`trace/` (agent trace rail), `graph/` (entity graph, deterministic `layout.ts`), `evidence/` (drawer, re-run), `dialogs/`, `dossier/`.
`landing/` belongs to the landing lane.
